# Security

Report a vulnerability privately through
[GitHub's advisory form](https://github.com/ShanedixonGit/repohopper/security/advisories/new),
not in a public issue. Expect a reply within a week.

In scope: anything that lets a web page, a repository name or a registry entry make Repohopper do
something it should not, such as opening a non-HTTPS or attacker-chosen destination, putting
unexpected text on the clipboard, or reading data beyond the current tab's address; and anything
that contradicts the [privacy policy](docs/privacy.md).

Out of scope: problems in the services Repohopper links to. Report those to their maintainers.

Only the latest release is supported.
